## 玩法

- **斜 45° 等距战场**：约 48×42 ~ 56×50 格的辽阔战场（面积约为旧版 5 倍），格子放大到 52px 上下一眼看清地形细节；战场远大于屏幕，单指拖动平移、双指/滚轮缩放，「⛶ 全图」一键纵览全局
- **山河各有相貌**：山分尖峰、浑圆、双峰、巉岩四种形态并随高度图错落起伏，不再千人一面；河流三层正弦蜿蜒、沿程宽窄渐变，宽处成江、窄处成溪，架桥必择窄处，大江宽处泊连环战船（水军可登，陆军踏船而过）；山地丘陵高低不平，谷地坡地一目了然
- **回合制战棋**：方形网格战场，武将带兵种与兵力，走位、攻击、反击、占点
- **兵即血槽，带兵定强弱**：hp 就是这支部队还剩多少人马——名将统带七八千，虎豹骑、白毦兵这类精锐营伍四五千，新募之兵两千出头。人马越多出手越重（兵势），打到只剩残部则气势涣散；众寡悬殊时兵多的一方压着兵少的一方打
- **地形决定战术**：
  - **高地**（山地/城池）：居高临下伤害 +18%，远程射程 +1；仰攻则吃亏
  - **林地**：隐蔽——所受远程与谋略伤害 -25%；可被火攻点燃形成火场
  - **河流**：仅水军可渡，且阻断远程弹道；水军入水攻防 +25%
  - **城墙**：不可通行，阻断远程
  - **城池/营寨据点**：占领后每回合回血回士气、防御加成，旗帜随归属变色
- **控制区（ZOC）**：步兵/枪兵/骑兵相邻会拦住敌军去路，无法自由穿过阵线；弓兵谋士无控制区；赵云「一身是胆」等特性可无视
- **战术机制**：**夹击**（合围同一目标每人 +10%，上限 +30%）、**骑兵冲锋**（奔袭 3 格以上伤害递增）、**枪兵结阵**（原地固守减伤，反击骑兵伤害翻倍）、**士气崩溃**（残兵更易被打崩）；远程被贴身无法还击
- **46 种武将特性**：关羽「武圣」、张飞「咆哮」、赵云「一身是胆」、诸葛亮「卧龙」、吕布「无双」、周瑜「火烧赤壁」、甘宁「锦帆」、张辽「威震逍遥津」…… 87 位武将人手至少一个，编队搭配与敌情查看时均可见
- **移动范围一目了然**：选中武将后，可移动格亮蓝高亮并勾勒区域轮廓，范围外自动压暗；红色斜纹为攻击可达范围，黄色箭头为行军路径预览
- **伤害全透明**：点击敌将即可查看预计伤害与每一条加成来源（高地/夹击/冲锋/相克/隐蔽……），点哪块地就显示哪块地的效果
- **兵种相克**：骑兵克弓兵/谋士，弓兵克步兵，步兵（枪阵）克骑兵，谋士克步兵；战场放大后骑兵大幅提速（12 格/回合）、步兵小增（6 格）、弓谋微增（5 格），机动差异更悬殊；谋士远程谋略可治疗；水军可渡江河
- **武将技**：消耗士气释放。**一将身怀二至三技**——武技（青龙偃月、破军、神刀）与谋略（火攻、水淹、八阵图、五雷正法）兼备，卡片上每条计都标着类别（火/水/雷/石/治/励/阵/心）与地势偏好，点哪一条施哪一条。诡道诸计各有奇效：**火攻**点燃林地营寨、**诈败**诱敌乱阵、**反间**令敌将阵前倒戈砍向自己人、**蛊惑**乱心乱军、**招降**劝得败军倒戈来投、**伏兵**林间四起、**八阵图**困敌动弹不得、**空城**退敌……共 40 余种
- **一计一式，各有其形**：每种计略都有专属动画——火攻烈焰腾空、水淹洪波涛涛、五雷紫色天雷轰顶、落石巨石砸落扬尘、八阵阴阳双鱼旋转、攻心紫气旋涡、仁德金光回春、兵刃交错刀光——一眼便知放的哪一计
- **因地制宜**：大范围计略「吃」地势——火攻须择林地、草莽、营寨、舟船（对上则威力 +40% 并燃起火场），水淹须择低洼水泽（对上则洪水泛滥、断绝行军），落石须依山势（巨石堵道，数回合后渐清）。瞄准时全图标出宜用之地（青光）与不宜之地（灰暗），用地对了威力倍增，用错了大打折扣
- **战场遗留物**：计略会真实改写战场——**火场**灼烧过境之敌、**洪水**非水军不得涉渡、**乱石**彻底堵死山道、**八阵**困住入阵者。它们能截断行军路线、逼敌军改道，用水淹堵住峡谷、再以火攻封死桥头，便是演义里「水火无情」的打法
- **天时可卜**：敌我各行动一回合后天时演变一次，且下一轮天象提前标出（顶栏「晴 → ☂」）——下一轮起风就该把火攻留到那时放，下一轮大雨则火计要趁早。雨抑火势、风助火势、大雾锁远程、大雪封山行军迟缓，天雷更是在暴雨中威力倍增
- **无名的兵**：虎豹骑、陷阵营、青州兵、白毦兵、丹阳兵、无当飞军、西凉铁骑、白马义从、藤甲兵、黄巾力士、蛮兵、幕府谋士、随军医官等 24 类营伍入册，各有兵种、战力与技能，以兵种字徽记与名将画像区分
- **胜利条件**：歼灭 / 斩杀敌将 / 占领据点 / **攻入敌城**（占城后还须守住一整轮）/ **夺取红旗**（夺得敌军帅旗还要活着送回本阵，携旗者阵亡则旗落原地任人再夺）/ 坚守 N 回合 / 护送抵达，随关卡进度逐步解锁
- **武将收集与养成**：过关获得经验与金币，招致 30+ 位三国名将；武将升级成长，可金币训练；出阵席位随战功由 5 位增至 8 位——对面动辄十万大军，五员将佐可不够看
- **智能敌军**：AI 会抢高地、躲林地、风筝脱身、集火夹击、夺点守点，且逐计掂量身怀的数技挑最狠的一手放——火攻专挑林中敌群且天不下雨、水淹专找低洼水泽、落石专堵山地夹道、反间直取主帅、招降专劝残兵；敌方武将同样身怀数计，会挑对我军最毒的一手，用兵火候随关号渐进（起初莽撞冲杀，后期会用计、会截旗、会围杀主帅）
- **大军压境**：敌军不再是三五员将佐对砍，而是「N 员名将 + M 队营伍」的演义规模——首关 5 个单位，末关 17 个（8 将 9 队），斩将易、破军难
- **关卡设计**：14 章按演义时间线推进——黄巾之乱、讨董联军、群雄割据、官渡、赤壁、荆襄、入蜀、汉中、襄樊、夷陵、北伐、五丈原、三分归晋；敌军强度随关号陡升（前段温和、后段峻急），并按目标类型反调——坚守关的敌军格外凶悍、攻城夺旗关的敌阵相对透气，使整条难度曲线平滑递增（AI vs AI 全量模拟：前 30 关胜率 63% → 后 30 关 23%，真人操作另有余裕）。硬仗正面强攻得不偿失，须借地势用计、调动敌军
- 断点续战、伤害飘字与技能特效动画、火场燃烧特效、深色模式、桌面端可玩

## 使用

- **电脑**：双击 `index.html` 用浏览器打开即可
- **手机浏览器**：目录放到静态服务器，访问后「添加到主屏幕」即可离线游玩
- **安卓 APK**：`dist/sanguo-v1.0.0.apk`（约 2MB），传到手机安装即可，最低支持 Android 8.0

本地预览：

```bash
cd sanguo
python -m http.server 8124
# 打开 http://127.0.0.1:8124
```

## 重新打包 APK

复用已验证的原生 WebView 壳（无需 Gradle / Android Studio）：

```bash
bash tools/build-apk.sh        # 产物：dist/sanguo-v1.0.0.apk
```

- 依赖：JDK 17+ 与 Android SDK（build-tools;34.0.0 + platforms;android-34），SDK 位于 `../.cache/sdk`，或用 `ANDROID_HOME` 指定
- 签名密钥 `dist/sanguo.keystore`（口令 `sanguo-app`），升级版本必须用同一密钥；版本号在脚本顶部 `VERSION_CODE` / `VERSION_NAME`
- 改了 Web 代码后重新执行脚本即可；图标由 `tools/make-icon.py` 生成

## 目录结构

```
sanguo/
├── index.html            入口（首页/关卡/编队/战斗/结算/武将/设置）
├── manifest.webmanifest  PWA 清单
├── sw.js                 Service Worker（离线缓存）
├── assets/
│   ├── css/app.css       国风水墨配色（浅色/深色）
│   ├── js/core.js        战棋引擎：地图生成、移动、伤害、技能、胜负
│   ├── js/data.js        60+ 武将、20+ 武将技、14 章 100 关数据
│   ├── js/ai.js          敌方 AI（目标感知：夺点/护送/斩将/坚守）
│   ├── js/game.js        战斗流程与结算、存档序列化
│   ├── js/store.js       本地存档：进度/养成/编队/金币
│   ├── js/ui.js          吐司/对话框/主题
│   ├── js/render.js      Canvas 战场渲染与动画
│   ├── js/battle.js      战斗页交互
│   ├── js/app.js         路由与页面
│   └── img/              AI 生成美术（封面/场景/23 位名将头像）
├── android/              APK 壳工程
├── dist/                 构建产物与签名密钥
└── tools/
    ├── test-battle.js      数据校验 + 100 关自动对战模拟（难度曲线）
    ├── smoke.js            Playwright 端到端测试
    ├── shots.js            视觉截图
    ├── make-icon.py        启动图标生成
    └── build-apk.sh        一键构建 APK
```
